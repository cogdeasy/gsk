## Target patterns

### SI-CO-001 - CO totals or line item table accessed directly

- Severity: blocker
- SAP topic: CO: universal journal ACDOCA
- Target: COSP, COSS, COEP and COBK are merged into the universal journal. Use ACDOCA based CDS views for actual and plan cost reporting.

### SI-TECH-003 - Obsolete ABAP syntax

- Severity: major
- SAP topic: ABAP for Cloud language restrictions
- Target: Header lines, OCCURS, MOVE and TABLES work areas are not permitted in clean-core code and block the move to ABAP for Cloud. Use inline declarations and work areas.

### SI-TECH-005 - SELECT * used

- Severity: minor
- SAP topic: Code pushdown / HANA performance guidance
- Target: Column stores penalise wide reads. Select only the fields the program uses.

### SI-TECH-004 - Database read inside a loop

- Severity: critical
- SAP topic: Code pushdown / HANA performance guidance
- Target: Nested SELECTs dominate runtime on HANA and will not meet the wave cutover batch windows. Rewrite as a set based read with a join or FOR ALL ENTRIES.

### SI-GXP-001 - GxP object has no automated test evidence

- Severity: critical
- SAP topic: Computer system validation (GAMP 5 / Annex 11)
- Target: GxP-relevant and GxP-critical objects need documented test evidence per wave. Add an ABAP Unit test class and link it to the validation package so regression evidence is generated automatically.

### SI-MM-003 - Material number hard coded to 18 characters

- Severity: critical
- SAP topic: Extended material number field length
- Target: MATNR is 40 characters on S/4HANA. Replace CHAR18 typing, LENGTH 18 declarations and (18) offsets with TYPE matnr.

### SI-TECH-006 - CLIENT SPECIFIED used

- Severity: major
- SAP topic: ABAP for Cloud language restrictions
- Target: Cross client access is not allowed in ABAP for Cloud and is a data segregation risk under RISE. Remove the addition and rely on automatic client handling.

### SI-TECH-002 - Obsolete function module called

- Severity: critical
- SAP topic: Obsolete frontend services
- Target: WS_UPLOAD / WS_DOWNLOAD / UPLOAD / DOWNLOAD are obsolete. Use cl_gui_frontend_services, or for background interfaces an application server path or the file adapter.

### SI-MD-002 - Customer or vendor master read directly from the legacy table

- Severity: minor
- SAP topic: Business Partner mandate / CVI
- Target: Reads still work through compatibility views but should move to I_Customer / I_Supplier so the BP attributes are available.

### SI-SD-002 - Classic SD credit management objects used

- Severity: critical
- SAP topic: FSCM credit management successor
- Target: Classic credit management (FI-AR-CR) is not available. Rebuild against SAP Credit Management (FIN-FSCM-CR) using the UKM master data and exposure APIs.

### SI-SD-001 - Sales document status tables VBUK/VBUP accessed

- Severity: blocker
- SAP topic: SD: status tables removed
- Target: VBUK and VBUP are removed. The status fields are now part of VBAK and VBAP; read them from the sales document CDS views.

### SI-FI-001 - FI index or totals table accessed directly

- Severity: blocker
- SAP topic: FI: universal journal ACDOCA
- Target: Secondary index and totals tables are replaced by the universal journal. Read ACDOCA through I_JournalEntryItem or the compatibility views.

### SI-FI-002 - BSEG/BKPF read where the universal journal should be used

- Severity: major
- SAP topic: FI: universal journal ACDOCA
- Target: BSEG and BKPF still exist but no longer carry the full line item picture. Reporting reads must move to ACDOCA.

### SI-OM-001 - NAST based output determination used

- Severity: critical
- SAP topic: Output management (BRF+) successor to NAST
- Target: Output control on S/4HANA is BRF+ based. NAST processing and RSNAST00 reprocessing must be rebuilt on the output management framework, including the error retry path.

### SI-MD-001 - Customer or vendor master written outside Business Partner

- Severity: blocker
- SAP topic: Business Partner mandate / CVI
- Target: The Business Partner is the single entry point for customer and supplier master data. Direct writes to KNA1, KNB1, LFA1 or LFB1 break CVI synchronisation; use the BP API or MDG replication.

### SI-TECH-007 - COMMIT WORK inside a loop

- Severity: major
- SAP topic: LUW handling / interface restartability
- Target: Committing per iteration leaves partial postings after a failure, which is not acceptable for a GxP interface. Use a bounded commit block with restart capability.

### SI-MM-002 - Material document tables MKPF/MSEG accessed directly

- Severity: blocker
- SAP topic: MM-IM: MATDOC single document table
- Target: MKPF and MSEG are replaced by MATDOC. Use I_MaterialDocumentItem or the NSDM_MIG compatibility views; do not assume MKPF/MSEG field semantics or indexes.

### SI-MM-001 - Aggregate stock table accessed directly

- Severity: blocker
- SAP topic: MM-IM: material inventory management data model
- Target: Stock quantity fields in the aggregate tables are not maintained on S/4HANA. Read stock from the released CDS views (I_MaterialStock and the NSDM compatibility views) which are backed by MATDOC.

### SI-PP-001 - Classic MRP list tables accessed
